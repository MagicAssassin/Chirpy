# Chirpy
This is a guided project from boots.dev

This project ho through how to handle http web request with json, Authentication and database implementation with postgre.

This porject will require a postgers database and a .env file with these varibles:
  - DB_URL (your database url)
  - PLATFORM ("dev")
  - SECRET (Your Secrete Key)
  - POLKA_KEY (API Key for the webhook)
